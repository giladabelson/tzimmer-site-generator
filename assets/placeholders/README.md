# תמונות המחשה (placeholders)

הקבצים כאן הם תמונות המחשה: תמונות שממלאות את מקום הצילום האמיתי, כדי שאפשר
יהיה לבנות אתר לצימר לפני שצילמנו אותו.

**כל תמונה כזו מוצגת באתר עם תווית גלויה: "תמונת המחשה - טרם צולם".**

## מה יש כאן בפועל

הפקודה `npm run placeholders` יוצרת בקוד שדות צבע מופשטים, בלי חדרים, רהיטים או
נופים. הסט שנשלח עם הפרויקט הוחלף מאז בצילומים מורשים: תצלומי Unsplash ופנורמות
360° של Poly Haven ברישיון CC0. הפירוט המלא, קובץ אחר קובץ, נמצא ב-`LICENSES.md`
שלצד הקובץ הזה.

שני הסוגים מותרים, כל עוד מתקיימים שני התנאים האלה:

1. כל תמונה מוצגת באתר עם התווית הגלויה.
2. אף תמונה איננה צילום של נכס אמיתי שמשווק להשכרה.

כלומר: מה שמופיע כאן לא חייב להיות מופשט, אבל הוא חייב להיות מסומן, והוא חייב
להיות תמונה שמותר לנו להשתמש בה.

## להחליף בסט משלכם
שמרו את אותם שמות קבצים (`hero.jpg`, `gallery-01..05.jpg`, `pano-01..03.jpg`)
ותחליפו את הקבצים כאן. אין צורך לגעת בשום קובץ אחר.

הפנורמות חייבות להיות **equirectangular** ביחס 2:1.

אם החלפתם את הסט, עדכנו גם את `LICENSES.md` כדי שיישאר נכון.

## מה אסור
אסור להכניס לכאן צילום של צימר אמיתי שלא צילמתם בעצמכם, גם לא "רק להדגמה".
צילום הוא יצירה מוגנת — הזכויות בדרך כלל אצל הצלם, לא אצל בעל הצימר.
