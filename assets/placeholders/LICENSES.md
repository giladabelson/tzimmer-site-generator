## מרקמים

`texture-paper.jpg` ו-`grain.png` נוצרו בקוד על ידי `npm run placeholders`
(צורות ורעש מופשטים, ללא מקור חיצוני).

## החלפה בסט משלכם

תחליפו את הקבצים כאן באותם שמות. אין צורך לגעת בשום קובץ אחר.
`npm run placeholders` לא ידרוס קבצים קיימים — צריך `--force` בשביל זה.
