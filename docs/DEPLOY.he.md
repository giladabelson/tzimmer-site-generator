# העלאה לאוויר - Cloudflare Pages

עלות: **אפס**. אין כרטיס אשראי, אין תקרת תעבורה, אין הגבלת מבקרים.
כל צימר מקבל פרויקט משלו ותת־דומיין משלו, כדי שאפשר יהיה לחבר לו דומיין
פרטי בהמשך בלי לגעת בשאר.

## פעם אחת בחיים

1. פותחים חשבון חינם ב-<https://dash.cloudflare.com/sign-up>.
2. בטרמינל, בתיקיית הפרויקט:

   ```
   npx wrangler login
   ```

   ייפתח דפדפן, מאשרים, סוגרים. זהו.

## להעלות צימר

```
npm run deploy -- --slug=kramim-bagalil
```

מה זה עושה: בונה את האתר, מריץ את בדיקות התמונות, ומעלה את `dist/kramim-bagalil`
לפרויקט Cloudflare Pages בשם `kramim-bagalil`. בפעם הראשונה הפרויקט נוצר לבד.

הכתובת שמתקבלת: `https://kramim-bagalil.pages.dev`

רוצים שם פרויקט אחר מה-slug:

```
npm run deploy -- --slug=kramim-bagalil --project=kramim-galil-demo
```

## לעדכן אחרי שינוי תוכן

אותה פקודה בדיוק. Cloudflare שומר גרסאות, אפשר לחזור אחורה מהדשבורד.

## לחבר דומיין .co.il אחרי שהלקוח משלם

1. הלקוח קונה דומיין (ישראייד, Domain The Net, GoDaddy - כ-40-80 ₪ לשנה).
2. ב-Cloudflare: **Websites → Add a site** → מזינים את הדומיין → בוחרים תוכנית **Free**.
3. Cloudflare נותן שני שרתי DNS. נכנסים לממשק של רשם הדומיין ומחליפים שם את
   שרתי ה-DNS לשניים האלה. זה מתעדכן תוך כמה שעות.
4. ב-Cloudflare: **Workers & Pages → הפרויקט של הצימר → Custom domains →
   Set up a domain** → מזינים `www.example.co.il` ואז גם `example.co.il`.
5. תעודת ה-SSL נוצרת אוטומטית. אין תשלום על אף אחד מהשלבים חוץ מהדומיין עצמו.

הערה: `.co.il` דורש שהרשם יאפשר שינוי שרתי DNS. כל הרשמים הישראליים מאפשרים.

## חלופה בלי טרמינל

בדשבורד של Cloudflare: **Workers & Pages → Create → Pages → Upload assets**,
וגוררים לשם את תיקיית `dist/<slug>`. מתאים אם מישהו אחר צריך להעלות עדכון.

## מה לא צריך

אין שרת, אין מסד נתונים, אין Node באוויר, אין תעודת SSL בתשלום, אין CDN בתשלום,
ואין שירות חיצוני שהאתר תלוי בו בזמן ריצה.
