# אתרי צימרים - מחולל אתרים

מחולל אתרים סטטיים לצימרים בישראל. כל צימר מקבל אתר עמוד־אחד בעברית, עם סיור
וירטואלי והזמנה ישירה בוואטסאפ. אפס עלות אחסון, אפס שירותים בתשלום, אפס שרת.

**למה זה קיים:** צימר ממוצע משלם ל-Booking עמלה של 15-17% ועוד 1.1-3.1% עמלת
סליקה. ב-2,000 ₪ ללילה ו-100 לילות בשנה זה 30,000-34,000 ₪ שיוצאים מהכיס.
כל תפקידו של האתר הזה הוא להזיז הזמנות לערוץ ישיר, מהטלפון, עכשיו.

---

## התקנה

```
npm install
```

## להוסיף צימר חדש

```
npm run new-property -- --slug=neve-tzuf --name="נווה צוף"
```

זה יוצר `properties/neve-tzuf/`. **זו התיקייה היחידה שנוגעים בה.** בפנים:

| קובץ | מה זה |
|---|---|
| `property.md` | כל התוכן. כל שדה מוסבר בהערה בתוך הקובץ. |
| `images/` | צילומים אמיתיים של הצימר. |
| `panoramas/` | תמונות ‎360° (equirectangular, יחס 2:1). |

אחר כך:

```
npm run build:one -- --slug=neve-tzuf
npm run deploy   -- --slug=neve-tzuf
```

אין צורך לגעת בשום קובץ תבנית. אם מצאתם את עצמכם עורכים משהו תחת `src/`
בשביל צימר מסוים - זה סימן שחסר שדה במודל התוכן, לא שצריך תבנית שנייה.

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm run new-property -- --slug=x` | יוצרת תיקיית צימר חדשה מהתבנית המתועדת |
| `npm run build:one -- --slug=x` | בונה צימר אחד ל-`dist/x` |
| `npm run build:all` | בונה את כל הצימרים, כל אחד לתיקייה נפרדת |
| `npm run dev -- --slug=x` | שרת פיתוח עם רענון חי |
| `npm run deploy -- --slug=x` | בונה ומעלה ל-Cloudflare Pages |
| `npm run preview -- --slug=x` | שרת מקומי שמגיש את `dist/x` (לבדיקה לפני העלאה) |
| `npm run check` | בדיקת התמונות בלבד |
| `npm test` | בדיקות הלוגיקה (יומנים, צבעים) |
| `npm run placeholders` | מייצר מחדש את תמונות ההמחשה |

## הכלל שמגדיר את הפרויקט: תמונות

צילום של נכס הוא **יצירה מוגנת**. פיצוי סטטוטורי בישראל מגיע עד 100,000 ₪
לכל יצירה, **בלי שצריך להוכיח נזק**. הזכויות כמעט תמיד אצל הצלם - לא אצל
בעל הצימר, גם אם הוא שילם על הצילום.

לכן: **אסור להכניס לאתר תמונה שנלקחה מ-Booking, Airbnb, פייסבוק, אינסטגרם
או מאתר קיים.** גם לא בהדגמה פרטית, גם לא "רק לרגע".

המערכת אוכפת את זה. לכל תמונה יש שדה `source`:

| ערך | מה מותר |
|---|---|
| `real` | צילום אמיתי של הצימר הזה שיש לנו זכויות עליו. מותר בכל מקום. |
| `placeholder` | תמונה מופשטת שנוצרה כאן בקוד. מותרת בכל מקום, ותמיד מוצגת עם תווית גלויה: **״תמונת המחשה - טרם צולם״**. |
| `stock` | סטוק או תמונה מיוצרת. מותרת **רק** ל-`role: texture` (רקע/מרקם). הבנייה נכשלת אם היא מופיעה כהירו, בגלריה או בפנורמה. |

בנוסף, הבנייה נכשלת אם:

* נתיב תמונה מצביע לכתובת חיצונית (`http://…`) או לקובץ מחוץ לפרויקט
* קובץ תמונה שמופיע ב-`property.md` לא קיים על הדיסק
* יש יותר מתמונת hero אחת, או אף אחת
* בפלט הבנוי נמצא משאב (תמונה, פונט, סקריפט, גיליון סגנון) שנטען משרת זר

## הסיור הווירטואלי - שלוש רמות

האתר בוחר לבד את הרמה הגבוהה ביותר שהתוכן מאפשר. אף פעם אין קופסה ריקה.

1. **`panoramas` מלא** → סיור ‎360° עם Pannellum, מתארח אצלנו, עם נקודות מעבר בין חדרים.
2. **`splatUrl` בלבד** → נגן Gaussian Splat של Luma, בלחיצה.
3. **שום דבר** → הגלריה הופכת לסיור: החלקה, מקשי חצים, כפתורי ניווט.

בשתי הרמות הראשונות שום דבר כבד לא נטען עד שהמבקר לוחץ.

## יומנים (זמינות)

`icalFeeds` מקבל כתובות iCal מ-Airbnb, Booking או Google Calendar. הן נקראות
**פעם אחת, בזמן הבנייה**, ומסמנות תאריכים תפוסים בלוח השנה. אין שרת ואין קריאה
בזמן ריצה.

יומן שלא נענה, איטי או פגום **לא מפיל את הבנייה** - האתר נבנה בלי החסימות שלו
ומציג ״לאישור זמינות סופית - שלחו הודעה״.

כדי לרענן זמינות צריך לבנות ולהעלות מחדש. אפשר לתזמן את זה (GitHub Actions
או Task Scheduler) אם רוצים רענון יומי.

## ההזמנה

אין שרת ואין מסד נתונים. בוחרים תאריכים ומספר אורחים, והכפתור בונה קישור
`wa.me` עם הודעה בעברית שכוללת את השם, התאריכים ומספר האורחים. בנוסף יש קישור
חיוג ישיר וכפתור העתקת מייל.

## הגלילה מספרת סיפור

הדף בנוי כרצף של "פעימות", לא כרשימת מקטעים. מנוע הגלילה הוא
[scroll-craft](https://github.com/nateherkai/scroll-craft) מאת Nate Herk (רישיון MIT),
מתארח אצלנו תחת `src/vendor/scrollcraft/` - בלי תלויות, בלי CDN, בלי מפתח API.
לקחנו רק את שכבת המכניקה שלו; מערכת העיצוב נשארה שלנו.

| פעימה | מה קורה | המכשיר |
|---|---|---|
| הגעה | ההירו ננעץ, והאור על התצלום יורד ככל שגוללים | `pin` + פרלקסה + הצללה שנקראת מ-`--sc-p` |
| הטיעון | המסך עומד והסיבות נערמות אחת-אחת | `pin` + `cue` |
| נוכחות | הסיור נחשף בניגוב מלמטה | `reveal` |
| החדרים | הגלריה | קרוסלה |
| מהות ומקום | מתקנים, מיקום, כללים | `in` + `stagger` |
| החלטה | הדף מפסיק לזוז ומתחיל להגיב | זרקור עכבר על כרטיס ההזמנה |

**התנועה היא תוספת, אף פעם לא תנאי לקריאה.** כל האנימציות מתקפלות תחת
`prefers-reduced-motion`, ויש שומר: אם המנוע לא נטען תוך שלוש שניות, סקריפט
זעיר מסיר את התכונות שמסתירות תוכן. אתר הזמנות לא יכול להישאר ריק בגלל
קובץ JavaScript שלא הגיע.

**המהלך הייחודי** הוא ״האור יורד״: המנוע מפרסם את התקדמות הגלילה כמשתנה CSS,
וההצללה ודירוג הצבע של תמונת ההירו קוראים אותו ישירות. גלילה בהירו מורידה את
האור על התצלום. זו שורת CSS אחת, בלי JavaScript משלה.

## ביצועים ונגישות

* אין שום משאב מדומיין חיצוני בזמן ריצה. פונטים, סקריפטים וסגנונות - הכול מקומי.
* פונטים: Frank Ruhl Libre לכותרות, Heebo לגוף. שניהם SIL OFL, מתארחים אצלנו,
  עם fallback שנמדד למידות המקוריות כך שאין קפיצת טקסט.
* scrollcraft, Lenis, Embla ו-Pannellum נטענים רק כשצריך אותם, אחרי הציור הראשון.
* כל האנימציות כבויות אוטומטית תחת `prefers-reduced-motion`.
* התמונות רספונסיביות, נטענות בעצלתיים, ועם תמונת טשטוש זעירה שמונעת קפיצה.

## מבנה

```
properties/<slug>/property.md   ← התוכן. רק כאן עורכים.
properties/_template/           ← התבנית המתועדת ל-new-property
assets/placeholders/            ← תמונות המחשה מופשטות, נוצרות בקוד
src/                            ← התבנית. לא נוגעים בה בשביל צימר מסוים.
scripts/                        ← CLI: בנייה, בדיקות, העלאה
dist/<slug>/                    ← הפלט. תיקייה נפרדת לכל צימר.
```
